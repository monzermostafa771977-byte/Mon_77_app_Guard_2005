# Mon_77 app Guard - V16.2 State Machine Core
تم تحويل النظام بالكامل إلى آلة حالة برمجية هندسية متكاملة (`GuardStateMachine.js`) لتدفق الخطوات التسع المعتمدة.
يحتوي الحزمة على:
1. `index.html` - واجهة المستخدم التفاعلية.
2. `GuardStateMachine.js` - آلة الحالة المتقدمة المحسوبة والمقاومة للتلاعب.
3. `sw.js` - Service Worker لدعم العمل بدون إنترنت.
4. `manifest.json` - إعدادات PWA الأيقونات.
5. `icon.png` - الأيقونة الرسمية المعتمدة.
