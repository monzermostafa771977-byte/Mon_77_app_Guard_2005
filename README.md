# Mon_77 app Guard — V17

## الجديد في V17
- **يعمل دون إنترنت:** Service Worker يخزّن الصفحة والأيقونات ومكتبتي التنسيق (Tailwind وFont Awesome). يلزم فتح التطبيق **مرة واحدة بإنترنت** ليكتمل التخزين.
- **تثبيت كامل:** زر «تثبيت» يعرض نافذة التثبيت الأصلية في Chrome، وله بديل من قائمة ⋮.
- **رسائل متجددة:** 12 رسالة إيمانية (آيات وأحاديث مع المصدر) و8 رسائل لصحة العين و10 لراحة العقل. تظهر تلقائياً كل 10 أو 20 أو 30 أو 60 دقيقة (يُضبط من بطاقة الرسائل) بتناوب: إيمان ← عين ← إيمان ← عقل.
- **🆘 لحظة ضعف:** تنفس موجّه (شهيق 4 وزفير 6)، ومؤقت 20 دقيقة لركوب موجة الرغبة، وآية، وخطوات عملية، وزر «عبرتُ اللحظة».
- **سلسلة الالتزام:** عدّاد أيام وعدّاد للحظات التي عبرتها، مع زر «بدأت من جديد» (يطلب الـ PIN إن وُجد).
- **استراحة العين:** مؤقت 20 ثانية تفاعلي.
- يشمل كل إصلاحات V16: المؤقت الدائم، وPIN المجزّأ، والأيقونة.

## الرفع إلى GitHub من الهاتف
1. فك الضغط من «الملفات»، ثم في المستودع: **Add file ← Upload files**.
2. اختر **كل الملفات** (بما فيها `sw.js`)، ثم **Commit changes**.
3. **Settings ← Pages ← Deploy from a branch ← main / (root) ← Save**.
4. افتح الرابط في Chrome مرة بإنترنت، ثم ⋮ ← **تثبيت التطبيق**.
5. عند رفع تحديث لاحقاً: غيّر رقم `CACHE` في `sw.js` (مثل `m77-v18`) ليصل التحديث للمستخدمين.

## حدود يجب معرفتها
- **الإشعارات:** تعمل غالباً والتطبيق مفتوح أو في الخلفية القريبة. الويب لا يضمن تنبيهات عند إغلاق التطبيق تماماً.
- الوضع الآمن طبقة داخل الصفحة وليس قفلاً على الهاتف. للحجب الحقيقي يلزم تطبيق أندرويد.
- التطبيق أداة مساندة وليس علاجاً. إن كنت تمرّ بأزمة نفسية حادة فتواصل مع مختص.
- **نسيت الـ PIN؟** امسح بيانات الموقع من إعدادات Chrome.
