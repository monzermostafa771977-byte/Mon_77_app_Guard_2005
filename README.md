# Monzer Hares Guard - النسخة المجتمعية الشاملة 🛡️

تطبيق مجتمعي ذكي يهدف لحظر المحتوى الإباحي وغير الأخلاقي، وتوفير أدوات التوعية الأسرية وإدارة وقت الشاشة بنقرة واحدة.

## محتويات المشروع:
- `index.html`: الملف الرئيسي للتطبيق بصيغة Web App متكامل يسهل رفعه وتشغيله فوراً على GitHub Pages.
- جاهز للاستخراج والرفع المباشر من الموبايل.
